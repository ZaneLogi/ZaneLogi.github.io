All control reaches the simulation as one pair of velocities, and nothing downstream knows where a value came from — which is how one engine serves both the demo and a played game. Two claims are tested hardest because neither shows in a screenshot: that the keyboard is latched, so releasing a key does nothing and there is a stop key; and that a key pressed during a Chapter 11 transition is deferred, not discarded. Both fall out of the source being a one-key register rather than a queue.
