← / → to change stage. Each stage is 91 bytes = 182 nibbles = 14×13, high-nibble first; column 13 is padding ($D in all 468 rows), leaving 13×13 blocks of 16×16. Each nibble indexes tbl_DACB_block_data ($DACB) for its 2×2 tiles and tbl_DABB_nametable_attribute ($DABB) for its palette.

The eagle is missing on purpose. Row 12 is empty in every stage file — the HQ and its walls are painted by code ($C331 / $E2A9), not stored per stage. That belongs to Base, not here.

Water animation is the real thing, not a loop: sub_C31D ($C31D) sets con_bg_pal_02 when frm_cnt_lo & $3F == 0 and con_bg_pal_01 at == $20 — a 32-frame swap driven here by a fixed-timestep 60.0988 Hz tick. The two sets differ only by swapping $3C↔$12 in palette 1.
