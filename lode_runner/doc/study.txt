ORG $609F
.start_game:
    call LOAD_LEVEL
    wait a key press
    .play_game:
    .game_loop:
        move player
        if not alive goto .died
        if GOLD_COUNT = 0, call ENABLE_NEXT_LEVEL_LADDERS
        if at top goto .level_cleared
        call HANDLE_TIMERS
        if not alive goto .died
        call MOVE_GUARDS
        if not alive goto .died
        goto .game_loop

.level_cleared:
    increase LEVELNUM
    increase DISK_LEVEL_LOC
    increase LIVES, not allow overflow, ie: max = 255
    add the score by 1500, play notes for 15 loops and add score by 100 every loop
    goto .start_game

.died:
    decrease LIVES
    call PUT_STATUS_LIVES
    call LOAD_SOUND_DATA
    play died tune
    if LIVES > 0 goto .start_game_
    otherwise,
        call RECORD_HI_SCORE_DATA_TO_DISK
        call SPINNING_GAME_OVER
        goto .key_pressed

ORG $63B3
DRAW_LEVEL_PAGE2: SUBROUTINE
    draw all sprites if VERBATIM is set nonzero
    or
        only allow max 45 ladders in a level including invisible ladders
            invisible ladders are not removed in the level map and store the positions at the other locations.
        check number of golds/guards/player
        add guards to the guard list and remove them in the level map, or don't add guards, if GUARD_COUNT >= 5
        add the player and remove it in the level map, or don't add player, if already exists
        the guards and the player are removed from the level map.
        traps are displayed as bricks
    call IRIS_WIPE

ORG $88A2
IRIS_WIPE: SUBROUTINE


6502 instructions
https://en.wikibooks.org/wiki/6502_Assembly
http://www.6502.org/tutorials/compare_beyond.html
BCC is branch if less than; BCS is branch if greater than or equal.

CMP NUM
-If the Z flag is 0, then A <> NUM and BNE will branch
-If the Z flag is 1, then A = NUM and BEQ will branch
-If the C flag is 0, then A (unsigned) < NUM (unsigned) and BCC will branch
-If the C flag is 1, then A (unsigned) >= NUM (unsigned) and BCS will branch
