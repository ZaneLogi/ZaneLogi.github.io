Galaga — demos

Standalone demos that validate a single mechanism of the Z80-faithful Galaga port in isolation. Each renders from the real extracted ROM data. ▶ Play the game — the full port lives at the project root.

Path player ↝

Shows the path builder: readable pathbuilder.js calls assembled to bytecode, proven byte-identical to the ROM by a live round-trip, then flown through the motion interpreter — the animated counterpart to SVG/path_01E8.svg. Watch the swoop build segment by segment; the mirrored "wishbone" pair.

Bonus-stage path player ↝↝

Shows the paths the challenging (bonus) stages use, one wave at a time. Pick a bonus stage (round 1-8) and a wave (1-5); the launcher join resolves each lefty/righty member — through the real PATH_INDEX/VARIANTS tables — to a ROM path block plus its start position, and flies both.

Combat fly-in path player ↝↴

Shows the token-bearing fly-in leaders (PATH_INDEX 0–5) the normal-play caravan launches. Pick a path and a mode — Formation (skip both branches, FB home), Stage 8+ (F0 attack-wave jump), Transient (F7 swoop + FE, despawn) — and watch the branch play through PathRunner's token layer.
