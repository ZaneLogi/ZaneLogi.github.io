Lunar Lander — thrust flame & the gameplay rotation range

The craft tilts within one half-circle only: head pointing left → up → right, so the engine always has a downward component — it can never point its head below horizontal. In engine-heading terms (the direction the thrust points): head-left = 0°, standing = 270°, head-right = 180° → the valid arc 0 → 270 → 180. Here that's parametrised as tilt ∈ [−90°, +90°] (0 = upright). This maps to the 9 stored poses (on-side → upright, stand = $4B64/$4DB6) plus their X-mirror — 17 attitudes ~11.25° apart, no upside-down, no yFlip.

The flame is a CPU-side reconstruction, not ROM data — no flame glyph exists in any of the three vector ROMs. The original almost certainly draws it programmatically (its length tracks the analog throttle, which a fixed glyph can't do); that routine lives in the un-dumped CPU program ROM. This plume is modelled on Asteroids' shared-cursor thrust shape and Seb Lee-Delisle's Moon Lander: a V off the nozzle, length = base + throttle×gain, scaled by a 3-step counter flicker, with the throttle smoothed.
