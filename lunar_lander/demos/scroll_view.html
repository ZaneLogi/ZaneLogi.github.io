Lunar Lander — scrolling terrain

The same terrain that screen.html draws (the $5000-$507E tile vector data, same scale + pad multipliers), scrolled horizontally. It slides one screen-width left (lander flying right, speed arrow →), then reverses and slides back (←) — a back-and-forth sweep. The endpoints are the same view, so each turnaround is seamless. The HUD rides on top. Tile sequence is the address-order approximation, same as screen.html (real CPU order TBD).

140 units/s
